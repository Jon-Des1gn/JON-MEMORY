# 🧠 JON MEMORY

Telegram-бот личной памяти с напоминаниями.

## Запуск

`pip install -r requirements.txt`

Скопируй `.env.example` в `.env`, вставь токен бота и запусти:

`python bot.py`

## MVP
- Память
- Напоминания и Telegram-уведомления
- Профиль
- Free / Pro / Max
- SQLite
- Красивое inline-меню

Следующий этап: AI-понимание естественных дат, умный поиск, повторяющиеся напоминания и оплата.
